# TaskFlow – Project Planning & Requirement Analysis

## 1. Project Title

TaskFlow – Task & Project Management System

## 2. Problem Statement

Student teams and small organizations often manage projects through
spreadsheets, notebooks, and messaging applications. This makes it
difficult to assign tasks, monitor progress, track deadlines, and
understand each team member's responsibilities.

A centralized web application is needed to organize projects and tasks
efficiently, improve collaboration, reduce missed deadlines, and provide
visibility into project progress.

## 3. Project Objective

To develop a web-based Task and Project Management System that enables
teams to create projects, assign and manage tasks, monitor progress,
track deadlines, and view productivity information through a centralized
dashboard.

## 4. Target Users / Stakeholders

### Administrator

- Manages users and user roles.
- Monitors projects and system reports.
- Manages system settings.

### Project Manager

- Creates and manages projects.
- Adds team members to projects.
- Creates, assigns, updates, and monitors tasks.
- Reviews project progress and reports.

### Team Member

- Views assigned tasks.
- Updates task status.
- Tracks deadlines.
- Collaborates with other team members.

## 5. Functional Requirements

### User Management

- User registration and login.
- Role-based access.
- Administrator user management.
- User profile management.

### Project Management

- Create projects.
- Edit project details.
- Delete projects.
- Assign team members to projects.
- Monitor project progress.

### Task Management

- Create tasks.
- Assign tasks to team members.
- Set task deadlines.
- Update task status.
- Edit and delete tasks.
- Track task progress.
