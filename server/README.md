# Gym Management System - Backend

## Description

This is the backend application for the Gym Management System.

The backend is developed using Node.js and Express.js and will provide
the API services required by the React frontend.

## Technologies

- Node.js
- Express.js
- CORS
- Dotenv
- Nodemon
